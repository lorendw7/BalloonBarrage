# Retired survey: retention and privacy

Updated November 6, 2026. The website's event voting/signup pages, links, QR images and QR-generation tooling have been removed. The old `/survey/`, `/ja/survey/` and `/en/survey/` routes are no longer published. Git history retains the questionnaire and prior website verification.

This website cleanup did not access responses, delete the external Google Form, or verify/change its acceptance settings. A previously shared direct form link may still work. Do not describe removal from the website as closing the external form or erasing collected information.

## Existing information obligations

- Only a nickname was required for voting. An email was requested only after opting in to future playtest invitations; no real name, student ID or phone was requested.
- Previously collected invitation emails remain limited to that stated purpose and **90 days from each signup**. Removing the website entry does not restart or cancel that limit.
- The creator must manually delete expired email-bearing responses and any private spreadsheet/export copies, and honor withdrawal/deletion requests through the form's **Contact form owner** control. No automatic deletion service was configured. Do not infer that any response exists or has already been deleted.
- Preserve private response access. Retain only aggregate voting counts if needed; never commit personal responses or exports to Git or expose them on the website.

The current development direction belongs to [Game design](../Design/GAME_DESIGN.md) and [Roadmap](../Design/ROADMAP.md), not to a new vote or registration campaign.
